PRIORIT | USER GUIDE

1. RUN THE APP

   Extract the ZIP. Open a terminal in the extracted folder containing
   package.json. With Node.js 22 or newer installed, run:

       npm ci
       npm run dev

   Open the local URL printed by Vite. On first launch, the dashboard shows
   25 sample tickets. Press Ctrl+C in the terminal to stop the server.
   Optional checks: npm test and npm run build.

2. VIEW THE KNIME RESULTS

   Open knime/priorit_results.csv. It contains 25 tickets and the Priority,
   Recommended_Action, Triggered_Rule, and Explanation columns.
   For example, ticket IT-1025 should show HIGH and R1.

3. IMPORT AND RERUN THE KNIME WORKFLOW

   Import knime/PriorIT-Demo.knwf into KNIME Analytics Platform.
   Open the output table of the last Rule Engine to see the saved decisions.

   To rerun on another computer, update the saved local paths:
   a. In CSV Reader, browse to knime/sample_tickets.csv in the extracted ZIP.
   b. In CSV Writer, select a new writable output filename, for example
      priorit_results_rerun.csv. Keep column headers enabled and RowIDs off.
   c. Apply the changes and execute the nodes left to right, ending with
      CSV Writer. Use a fresh output filename if If exists is set to Fail.
   d. Compare the new output with the included knime/priorit_results.csv.

README.md explains how PriorIT works.
